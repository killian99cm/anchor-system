## 二、补仓的数学：¥500 投进去会怎样

### 2.1 摊平成本的效果

```
当前：¥2,042 市值，-¥506 亏损（-19.86%）

如果再投¥500：
  总投入 ≈ ¥2,542
  持有亏损 ≈ -¥506
  收益率 ≈ -19.9% → -16.6%（摊平了3个百分点）

如果反弹+5%：
  不补仓：¥2,042 × 1.05 = ¥2,144，赚¥102
  补仓：  ¥2,542 × 1.05 = ¥2,669，赚¥127
  多赚：  ¥25

如果继续跌-5%：
  不补仓：¥2,042 × 0.95 = ¥1,940，多亏¥102
  补仓：  ¥2,542 × 0.95 = ¥2,415，多亏¥127
  多亏：  ¥25
```

> **¥500补仓的效果：反弹5%多赚¥25，再跌5%多亏¥25。本质上是用¥500赌一个5%的反弹——风险和回报完全不成比例。**

### 2.2 同样¥500，投给创新药

```
创新药今天+3.73%，风口已确认
¥500投创新药：
  如果明天+2% → 赚¥10
  如果本周+8% → 赚¥40
  而且你在买一个"正在涨"的品种，不是在"赌它不再跌"
```

## 三、"等反弹再走"的心理学陷阱

### 3.1 你心里在想的

```
"已经亏了477，现在割太疼了"
"说不定明天就反弹了"
"等回到-300我就走"
"反正银行卡还有5000，补一点摊平"
```

### 3.2 事实

| 你的想法 | 事实 |
|------|------|
| "已经亏了477，现在割太疼" | 7/13亏150时没割，现在亏477。**越等越疼。** |
| "说不定明天就反弹" | 7/16指数涨+0.64%，它跌-2.13%。**反弹它也未必涨。** |
| "等回到-300就走" | -300时你觉得能回-100。-100时你觉得能回本。**永远到不了你的目标。** |
| "补一点摊平成本" | ¥500摊平3%的成本。但¥500投创新药可能赚40。**机会成本更高。** |

### 3.3 这是行为经济学里的"处置效应"

> 投资者倾向于过早卖出盈利品种（你卖TMT50是对的），过晚卖出亏损品种（你死扛中证2000是错的）。你现在对中证2000的感觉，和7/6对诺安的感觉一模一样——当初诺安从-89拖到-348才割。**历史正在重演。**

## 四、如果补仓，最好的结果是什么

### 乐观情景（概率20%）：小盘股绝地反弹+10%

```
¥2,042 + ¥500补仓 = ¥2,542
反弹+10% → ¥2,796
累计亏损从-477 → -246
你等了2周，亏了246，终于"少亏了"
```

### 悲观情景（概率50%）：继续阴跌

```
每天亏30-90
两周后 → 再亏300-500
累计亏损 → -800到-1000
¥500补仓的钱也亏进去了
```

### 基准情景（概率30%）：横盘震荡

```
不涨不跌，但你的基金继续跑输指数
每天亏10-20
你的¥500被锁在里面，什么都做不了
```

> 三种情景，只有一种让你少亏。两种让你更惨。**这不是投资，是赌博。**

## 六、最后一个问题：如果清仓后它反弹了怎么办

这是你心里最担心的。我们来算：

```
清仓后中证2000反弹+10%：
  ¥2,042 × 10% = ¥204（你"亏"了204的反弹）
  
但同样这笔钱投创新药：
  创新药本周再涨5% → ¥2,042 × 5% = ¥102
  而且你买的是一个"正在涨"的趋势，不是"希望它不再跌"的祈祷
  
净差距：¥204 - ¥102 = ¥102
```

> **为了"不错过中证2000可能的+204反弹"，你愿意承受它"几乎确定的继续亏损"吗？过去21天它已经证明了自己的方向——向下。**
