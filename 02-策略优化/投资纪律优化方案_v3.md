# 投资纪律优化方案 v3.0

> 基于 v2.0 + 五维优化建议 | 吸收：三层金字塔、334建仓、冻结3天、卖飞补偿
> 调整：配比、黄金归入压舱石 | 保留：v2.0风口识别、月末淘汰、搜索铁律

## 一、三层金字塔（替代双轨制）

```
                    ┌─────────────────┐
                    │   🔥 卫星进攻层   │  15% (~¥5,500)
                    │  创新药+证券+半导体 │  快进快出，严格止损
                    │  单只≤¥3,000      │
                    ├─────────────────┤
                    │   🚀 核心增长层   │  25% (~¥9,000)
                    │  纳指+天弘通利    │  定投为主，PE>35才减
                    ├─────────────────┤
                    │   🛡️ 压舱石层     │  45% (~¥16,500)
                    │  债券×2+红利+黄金 │  永远不卖，年再平衡1次
                    ├─────────────────┤
                    │   💰 现金预备层   │  15% (~¥5,500)
                    │  余额宝           │  仅用于压舱石暴跌加仓
                    └─────────────────┘
```

### 为什么三层比双轨好

| 双轨的问题 | 三层的解决 |
|------|------|
| 黄金/通利定位模糊 | 黄金→压舱石，通利→核心增长，权责清晰 |
| 卫星亏了扛成核心 | **三层隔离，卫星止损不影响压舱石和核心** |
| 现金没规则 | 现金预备层：**只在压舱石暴跌时动用**，不参与卫星 |

## 二、四条新规则（从五维建议中吸收）

### 规则A：浮亏不加仓，盈利才加仓 ⭐⭐⭐

| 层级 | 加仓规则 |
|------|------|
| 压舱石 | 越跌越买（暴跌5%+→用现金预备层补） |
| 核心增长 | 定投不停，不因涨跌改变 |
| **卫星进攻** | **浮亏状态→一分钱不加。浮盈>3%→才能加第二笔。加仓≤首笔50%。** |

> 这条规则直接阻止中证2000式灾难：从-150补到-506。如果当时有这条规则，第一笔亏了就不会再加。

### 规则B：334分批建仓 ⭐⭐

```
首笔 30%：试错仓 → 看错了止损代价最小
  ↓ 连续2天上涨 + 浮盈>3%
第二笔 30%：确认仓 → 趋势确认
  ↓ 突破20日线 + 催化落地
第三笔 40%：重仓 → 全力出击
  ↓ 全程无浮盈 → 永远不加仓
```

> 替代原来的"每次¥500"——更科学，亏损控制更精确。

### 规则C：清仓资金冻结3天 ⭐⭐⭐

```
任何卖出回笼的资金 → 余额宝放满72小时 → 才能开新仓

为什么是3天：
  红利→中证2000转换：当天就转了 → 冲动决策
  卫星→诺安转换：当天就转了 → 冲动决策
  两次冲动 = -892
  
  3天后：冲动消退，理性回归
  80%的"手痒买入"会被这72小时过滤掉
```

### 规则D：卖飞补偿——留100份底仓 ⭐⭐

```
卫星止盈时：卖出99%，留100份（约¥100-200）不卖

好处：
  涨了：底仓跟着赚，不会"卖飞+75%"那样拍大腿
  跌了：100份亏不到¥20，忽略不计
  心理：彻底解决"卖了怕涨"的焦虑
```
