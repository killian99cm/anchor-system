# 📋 8/20 创新药时间止损执行预案

> 生成：2026-08-15 ｜ 目的：v3.3 首次"盈利端"规则实战，提前定死判定流程，避免临场情绪
> 规则原文：卫星持有 >30 天 + 跑输大盘 ≥5% → 强制卖出（规则手册 v3.3 §2.2）
> 数据：7/21 建仓（¥300 试探）→ 8/20 满 30 天

---

## 一、规则优先级（同日多规则冲突时）

> **-8% 止损 > 时间止损 > 恐慌豁免**
> （先处理最紧急的；若 8/20 恰逢恐慌日（大盘跌≥3% 或 板块跌≥5%），时间止损按恐慌豁免顺延 1 个交易日并记录，不硬执行）

| 冲突场景 | 执行 |
|------|------|
| 浮亏破 -8% + 满 30 天 | 按 -8% 止损流程（次日 14:30 板块确认）执行 |
| 浮亏 -5%~-8% + 满 30 天 + 跑输大盘 ≥5% | 时间止损：8/20 执行卖出 |
| 浮亏 -5%~-8% + 满 30 天 + 未跑输大盘 5% | 不触发时间止损，按 -8% 止损线继续监控 |
| 8/20 恐慌日 | 顺延 1 天，复盘记录豁免原因 |

## 二、判定流程（8/20 当日）

```
14:30  daily_advice 推送：创新药板块实时涨跌 + 是否触达 -8% 线（自动判定执行/延期）
21:30  收盘复盘：确认当日净值 + 板块 vs 大盘相对表现 → 正式判定
判定   → 触发：21:30 复盘后执行卖出（次日 14:30 前完成）
       → 未触发：更新 pending_actions，注明下次评估点
```

**跑输大盘判定口径**：创新药板块当日/近5日涨跌 vs 沪深300；数据不足时以「板块 vs 上证」近似并记录。

## 三、执行细则

| 项 | 内容 |
|------|------|
| 卖出对象 | 示例联接基金恒生港股通创新药ETF联接C（当前市值约 ¥2,498） |

| 金额预期 | 约 ¥2,400-2,500（以当日净值为准） |

## 四、错了怎么办（预案）

| 场景 | 应对 |
|------|------|
| 卖出后创新药大涨 | 记录规则成本（rule ledger missed/note），不追回——时间止损是纪律不是择时，接受 1-2% 的机会成本 |
| 卖出后继续跌 | 验证规则价值：避免 -8% 以上的深亏（rule ledger protected） |
| 判定当天净值异常（净值未出/停牌） | 顺延至净值确认日，期间不操作 |
