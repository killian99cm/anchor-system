### 3.4 卫星仓交易规则

```
买入：
  1. 催化必须明确可查（新闻/政策/财报）
  2. 技术面必须回调到位（不在高潮时追）
  3. 单次 ≤¥500，单板块 ≤¥2,000
  4. 买入前写：催化是什么？什么时候卖？亏多少止损？

卖出：
  1. 止盈：+10%卖1/3 → +20%卖1/2 → 剩余看趋势
  2. 止损：-8%无条件清仓（不犹豫！不等"反弹"！）
  3. 催化落地即走：利好兑现=卖出信号
  4. 持仓超3个月未盈利→清仓

禁止：
  1. 不追涨停板上的品种
  2. 不加仓亏损中的卫星品种（"摊平"是核心仓的玩法）
  3. 不同时持有超过4个卫星品种
```

## 六、两个仓位的关键区别（每次操作前对照）

| 维度 | 核心仓 | 卫星仓 |
|------|------|------|
| **买入理由** | 这个资产10年后还在吗？ | 这个催化下个月还在吗？ |
| **持有时间** | ≥3年 | 2周~3个月 |
| **最大亏损** | 不设止损，浮亏不割 | **-8%无条件清仓** |
| **加仓逻辑** | 越跌越买（摊平） | **绝不摊平亏损的卫星仓** |
| **卖出理由** | 基本面恶化 | 催化落地 / 止损线 / 3个月到期 |
| **目标收益** | 年化 6-8% | 年化 15-25%（但波动大） |
| **操作频率** | ≤2次/年 | ≤3次/月 |
| **研究深度** | 看3年趋势 | 看3周催化 |
