## 🧠 为什么需要 Anchor？

个人投资者最大的敌人不是市场，是自己
- **追涨杀跌** → 规则锁定买卖条件
- **情绪化加仓** → 浮亏不加仓铁律
- **频繁交易** → 月操作限额 4 笔
- **FOMO 焦虑** → 72h 冷静期 + 不FOMO禁令
- **没有系统** → 四层金字塔 + 清单式检查

> **Anchor = 把投资纪律固化为可执行的规则代码**

## 🏗️ 核心理念

```
         ┌──────────────────────────────────┐
   20%   │  🔥 卫星进攻     -8% 硬止损       │  波段交易
         │  行业ETF + 个股   不补仓不转换     │  高赔率下注
         ├──────────────────────────────────┤
   20%   │  🚀 核心增长     定投 + 大跌补仓   │  长期成长
         │  宽基指数 + QDII  低估时逐步建仓   │  穿越周期
         ├──────────────────────────────────┤
   45%   │  🛡️ 压舱石       永远不卖         │  组合基石
         │  债券 + 固收      每季再平衡      │  稳定收益
         ├──────────────────────────────────┤
   15%   │  💰 现金预备     暴跌补仓弹药      │  灵活机动
         │  余额宝/货基     保持流动性       │  等待机会
         └──────────────────────────────────┘
```

| 层级 | 目标 | 仓位 | 管理规则 |
|:--|:--|:--:|:--|
| 🛡️ 压舱石 | 稳定收益、防回撤 | 45% | 永远不卖，每季再平衡 |
| 🚀 核心增长 | 长期增值 | 20% | 定投为主，大跌补仓 |
| 🔥 卫星进攻 | 波段增强 | 20% | -8% 硬止损，浮亏不加仓 |
| 💰 现金预备 | 流动性 + 抄底 | 15% | 余额宝/货基，暴跌时动用 |

## 📜 规则体系

### 四条铁律
1. **浮亏不加仓** — 只平仓、不补仓、不转换，杜绝越跌越买
2. **-8% 硬止损** — 卫星层触及即砍，不考虑「反弹预期」
3. **72h 冷静期** — 任何买入想法强制冻结 72 小时再执行
4. **阶梯止盈** — +15% 卖 1/3 · +30% 卖 1/2 · +50% 清仓

### 六条永久禁令
```
🚫 不转换    🚫 不补仓      🚫 不当天换仓
🚫 不碰过剩  🚫 不定投卫星  🚫 不 FOMO 追涨
```

### 月度纪律
- **操作限额** ≤ 4 笔/月，超限冻结至下月
- **仓位检查** 每周末四层占比核对
- **红灯扫描** DDX转负、溢价率骤升、临近时间止损

## ⚡ 快速开始

```bash

cd anchor-system

# 编辑 portfolio_data.json 填入你的持仓

python 05-脚本工具/rebuild.py
```

## 📊 数据更新节奏

| 频率 | 操作 | 触发方式 |
|:--:|------|------|
| ⚡ 实时 | 查询行情 | `mx-data` API 调用 |
| 📅 每日 | 更新收盘数据 → rebuild | CI 或 "更新今日数据" |
| 📋 每周 | 仓位点检 + 周报 | "仓位点检" / "生成周报" |
| 📈 每月 | 月度归因 + 规则审议 | "月度归因" |
