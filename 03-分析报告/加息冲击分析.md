## 二、综合冲击评估

### 2.1 短期（加息当月）

```
纳指：      -5~10%（杀估值最快）
半导体：    -5~10%（高PE被首杀）
创新药：    -3~5%
债券：      -1~2%（中国跟跌但幅度小）
红利ETF：   +0~2%（银行+能源对冲）
黄金：      -3~5%

组合预估：  -2~4%（约-740~1480）
```

### 2.2 中期（加息后3-6个月）

```
中国央行大概率不跟（经济周期不同）
  → 债券企稳反弹
  → A股独立行情可能出现
  → 最大的冲击在纳指和港股创新药
```

### 2.3 长期（加息周期结束）

```
利率见顶＝科技股反弹最猛
纳指和半导体会在加息尾声提前上涨
黄金在加息末期开始走强
```

## 四、预防措施（如果真的加息）

### 4.1 不需要动的

| 品种 | 理由 |
|------|------|
| 债券×2 | PBOC不跟→跌幅有限→反弹快 |
| 515180红利 | 银行+能源对冲 |
| 余额宝 | 受益品种 |

### 4.2 需要调整的

| 品种 | 加息前 | 加息后 | 逻辑 |
|------|------|------|------|
| 纳指A+C | ¥3,385 | 不减，越跌越买 | 核心增长层：跌=更便宜的定投 |
| **半导体C** | ¥790 | 不加仓 | 浮亏时Anchor禁止加仓 |
| 创新药C | ¥2,497 | 不加仓 | 等风口确认 |
| 黄金 | ¥1,569 | 不加仓 | 加息结束前黄金承压 |

### 4.3 可以增加的保护

| 措施 | 时机 | 效果 |
|------|------|------|
| 提高余额宝比例 15%→20% | 加息确认后 | 现金收益上升 |
| 纳指定投加速（如果限购放开） | 加息中后期 | 科技股底部建仓 |
| 债券不动 | 全程 | PBOC不跟→跌幅有限 |
