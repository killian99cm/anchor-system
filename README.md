# ⚓ Anchor 投资管理系统 v3.3

> 109笔实盘迭代 · 13个月数据验证 · 量化规则驱动的个人投资框架

## 是什么

Anchor 是一套**规则驱动的个人投资管理系统**，不是选股策略、不是AI自动交易、不推荐具体产品。

它解决的核心问题：**用规则管住手，用数据代替直觉**。

## 核心理念

```
┌──────────────────────────────────┐
│  🔥 卫星进攻 20%   -8%硬止损     │
│  🚀 核心增长 20%   定投+大跌补仓 │
│  🛡️ 压舱石 45%    永远不卖       │
│  💰 现金预备 15%   暴跌补仓弹药   │
└──────────────────────────────────┘
```

### 四条铁律
1. **浮亏不加仓** — 只平仓、不补仓、不转换
2. **-8% 硬止损** — 卫星层触及即砍，不考虑"反弹"
3. **72h 冷静期** — 任何买入想法冻结72小时再执行
4. **阶梯止盈** — +15%卖1/3、+30%卖1/2、+50%清仓

### 六条永久禁令
不转换 · 不补仓 · 不当天换仓 · 不碰过剩产能 · 不定投卫星 · 不FOMO追涨

## 快速开始

```bash
# 1. Clone
git clone https://github.com/killian99cm/anchor-system.git

# 2. 创建你的持仓数据
cp 06-看板数据/portfolio_data_example.json  portfolio_data.json
# 编辑 portfolio_data.json，填入你的实际持仓

# 3. 生成看板
python 05-脚本工具/rebuild.py

# 4. 打开看板
# 双击 portfolio_analysis.html 即可
```

> ⚠️ **数据文件不上传 GitHub**。`.gitignore` 已排除 `portfolio_data.json`、`portfolio_snapshot.json`、`portfolio_holdings.xlsx`、`portfolio_analysis.html`。仓库中的 `*_example.*` 文件是脱敏示例。

## 数据更新节奏

| 频率 | 操作 | 方式 |
|:--:|------|------|
| 实时 | 查询行情 | `mx-data` API |
| 每日 | 更新JSON → rebuild → 检查DDX/溢价率 | 手动或 CI |
| 每周 | 生成周报 + 仓位点检 | 对Claude说"仓位点检" |
| 每月 | 月度归因 + 规则审议 + 版本升级 | 对Claude说"月度归因" |

## 技术栈

- **数据采集**: mx-data API (东方财富) / AKShare 兜底
- **数据处理**: Python (pandas, json)
- **可视化**: 纯HTML/CSS/JS 深色终端风看板（零依赖）
- **AI 辅助**: Claude（复盘分析、规则优化、报告生成）
- **自动化**: GitHub Actions 日度CI
