> **总亏损：-¥1,029 | 盈利率：39% | 平均持有：103天**
> 这不是运气不好——这是系统性问题。

## 二、三个致命模式

### 模式1：卖得太早——然后暴涨

| 基金 | 卖出时 | 卖出后涨了多少 |
|------|:--:|:--:|
| 易方达信息产业 | -9.49% | **+75.36%** 🚀 |
| 英大国企改革 | -0.90% | **+69.32%** 🚀 |
| 金信智能中国 | -0.90% | **+57.35%** 🚀 |
| 博时纳指C | +19% | 再涨+24.72% |
| 天弘创业板 | -6.45% | +17.01% |

> **规律：你卖掉的基金，平均在卖后涨了+35%。** 这不是选错了基金——是卖错了时机。你在基金"即将起飞"的时候选择了割肉。

### 模式2：行业基金 = 亏损机器

```
行业/主题基金清仓记录：
  软件服务     -616  军工混改    -226
  卫星产业     -116  信息产业     -52
  红利低波     -105  创业板      -32
  化工          -55  港股科技    -112
  银行（短线）   -9   科创50      -12
  ─────────────────────────────────
  合计：-¥1,335
```

> **10只行业/主题基金，全部亏损，无一例外。** 行业基金需要精准择时——你目前做不到。这也是为什么v2.0框架把卫星仓限制在4只，并设-8%止损。

### 模式3：好基金也拿不住

```
半导体量化 → +23.72%清仓（卖对了，之后仅涨+0.15%）
纳指C     → +19%清仓   （卖早了，之后涨+24.72%）
黄金      → +7%清仓    （卖早了，之后跌-15%←这次运气好）
红利      → +2.96%清仓 （之后涨+5.26%）
```

> 即使是盈利清仓，也只有半导体卖对了。其他都是卖早了。

## 三、根因：持有103天

```
你的平均持有周期：103天（约3.4个月）
优秀基金的年化收益：10-20%
3.4个月的实际收益：2.8-5.7%

但买卖一次的成本：申购费0.1-0.15% + 赎回费0.5%
每月交易2-3次 → 年化成本约3-5%

收益 - 成本 = 0甚至为负
```

> **你每3个月换一轮基金。交易成本吃掉了一半的收益。剩下的被"卖飞"和"割肉"吃掉了。**

---

## 四、v2.0框架如何解决这些问题

| 清仓历史的问题 | v2.0的解决方案 |
|------|------|
| 卖得太早 | **阶梯止盈**：+10%只卖1/3，+20%再卖1/3，剩余的让利润跑 |
| 行业基金亏钱 | **卫星仓上限4只** + **-8%止损** + **月度末位淘汰** |
| 好基金拿不住 | **核心仓永不卖**：债券/红利/纳指 → 持有≥3年 |
| 频繁交易 | **月操作≤4笔**（买入≤2+卖出≤2） |
| 持有太短 | **核心仓≥3年，卫星仓2周→3个月** |

## 六、一句话

> **28只清仓基金教会你一件事：你不是不会买——你是不会等。卖飞了75%的涨幅，割在了地板上，把时间都花在了买卖上而不是等待上。v2.0的核心逻辑就是用规则强迫你"等"——核心仓永远不卖，卫星仓设好止盈止损后让市场决定。**
