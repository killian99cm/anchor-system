## 一、六步进化闭环（制度化约定）

```
① 实践发生（操作/决策，decision_log 留痕）
② T+3 复盘判定（correct / wrong / neutral，每笔必判）
③ 教训提炼（异常判定/反面案例 → 一条可复用经验，入教训库）
④ 改进提案（经验 → 规则修改/新增，登记本台账，标注来源教训/实践）
⑤ 回测验证（可量化的提案先过 09-backtest 证据链，再谈落地）
⑥ 落地 + 效果跟踪（版本更新 → 后续归因验证有效性：有效保留 / 无效回滚）
```

**验收标准**：每个提案必须回答三维原则——对「收益率 / 正确率 / 波动」的影响；无法量化者标注"按原则判断"。
