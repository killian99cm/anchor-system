# 投资者深度画像

## 基本盘
- 学生，自学嵌入式机器人，初学者水平
- 总资产~¥36,500（基金¥27,400+股票¥5,500+现金¥3,600）
- 银行卡备用~¥4,400，总可调用~¥8,000
- 风险承受：中等（能承受日亏-700但不恐慌）

## 行为模式（基于109笔交易+28只清仓基金）

### 最大弱点
1. **持有太短**：平均103天就卖。卖飞了+75%、+69%、+57%的涨幅
2. **过度交易**：35天109笔=3.1笔/天。交易成本吃掉一半收益
3. **卖盈持亏**：盈利的拿不住（纳指+19%就卖），亏损的死扛（中证2000从-150拖到-506）
4. **转换冲动**：两次转换亏损-892，占总投资亏损60%
5. **FOMO追涨**：看到银行/兴业/煤炭涨了才问要不要买

### 核心优势
1. **纪律性强**：给定明确规则后能严格执行（证券+500/诺安清仓/不割创新药）
2. **不恐慌**：5000+跌停日没有乱操作
3. **学习速度快**：两周内从频繁交易转向框架化操作
4. **数据诚实**：主动提供完整交易记录和亏损数据

## 个性化建议规则

### 必须反复提醒的
- "你平均103天就卖→卖飞了+75%。这次拿住。"
- "你上次转换亏了-892。这次不换。"
- "看到涨了才想买=FOMO。等回调。"
- "定投只做核心仓。卫星仓不设自动定投。"

### 适合你的策略
- 核心仓（债券/纳指/红利）→ 买了不管，强制长期
- 卫星仓→ 设好止盈止损线，让规则代替判断
- 不碰主动基金转换
- 不碰行业主题基金（历史上全部亏损）
- 定投只用于核心仓

### 不适合你的策略
- 短线波段（你拿不住盈利）
- 行业轮动（103天不够一个行业周期）
- 个股（研究深度不够）
- 网格交易（你会越跌越买然后死扛）
