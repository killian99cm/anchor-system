## ✅ 吸收（7条）

---

### 1. 天弘通利A → 压舱石定位标注

**建议原文**：天弘通利A为偏债混合型基金，风险收益特征更接近压舱石，层级边界不清。

**三问评估**：

| 问题 | 答案 |
|------|------|
| 能阻止历史亏损？ | 7/17恐慌日，天弘通利单日跌-45元。如果当时就把它当压舱石看待，不会在复盘时反复纠结"它是进攻还是防御"——精力浪费本身就是成本 |
| 规则冲突？ | 无。压舱石规则是"永远不卖"，天弘通利定投¥150/周本身就符合 |
| 一个月验证？ | 能。看一个月内它的日波动率是否<2%——符合压舱石特征 |

**为什么不直接移仓**：核心增长层现在只有纳指+通利两只。纳指限购¥10/天无法补充。通利移走后核心增长只剩纳指——太单薄。等限购放开再加一只宽基，才把通利正式归入压舱石。

**改进后效果**：看板中通利显示为"核心增长（偏压舱石）"。复盘时不再纠结其定位。恐慌日不再因为它跌了而焦虑。

### 2. 再平衡规则

**建议原文**：体系有明确目标比例但无再平衡规则。

**三问评估**：

| 问题 | 答案 |
|------|------|
| 能阻止历史亏损？ | 7/17本周，卫星层从15%被动跌到12%，然后7/21反弹到18%。如果没有再平衡规则，你不知道"18%的卫星是不是太多了"。明确偏离线=知道什么时候该动手 |
| 规则冲突？ | 无。填补空白，不冲突 |
| 一个月验证？ | 能。月度归因时检查一次 |

**改进后效果**：

```
以前：卫星涨了不敢卖（怕踏空），跌了不敢买（怕接刀）
以后：月度归因时看到数字→偏离>5%→触发调仓→不是"我觉得"，是"规则说"
```

### 3. 恐慌日豁免精确化

**建议原文**：当前定义模糊——"≥3000只下跌"无明确量化标准和豁免期限。

**三问评估**：

| 问题 | 答案 |
|------|------|
| 能阻止历史亏损？ | 这个规则本身已经阻止了7/17的恐慌割肉。但模糊的边界可能导致未来"每次大跌都豁免"→止损形同虚设 |
| 规则冲突？ | 无。是现有规则的精确化 |
| 一个月验证？ | 能。下次恐慌日直接对照 |

**改进后效果**：

```
以前：≥3000跌→"豁免"→多久？不知道
以后：大盘≥3%或板块≥5%→延迟1个交易日→次日收盘重判

例子：
  周四科创50-4.09%→触发恐慌豁免→不执行止损
  周五收盘→重新评估→如果继续-2%以上→执行止损
  如果反弹→豁免自动解除
```

### 4. 时间止损（30天）

**建议原文**：卫星仓长期横盘既不止损也不止盈，占用资金效率。

**三问评估**：

| 问题 | 答案 |
|------|------|
| 能阻止历史亏损？ | **中证2000是最佳案例。** 6/30转入→持有21天亏-506。如果有30天时间止损：①7/14亏-204时触发警报 ②持仓满30天（7/30）触发强制卖出 ③不会拖到-506 |
| 规则冲突？ | 无。是-8%价格止损的补充——价格没触发但时间到了 |
| 一个月验证？ | 能。创新药试探仓7/21买入，8/20满30天 |

**改进后效果**：

```
卫星仓两把刀：
  价格刀：-8% → 立刻砍
  时间刀：30天+跑输大盘5% → 也砍

中证2000如果在7/14触发时间止损警报，就不会从-204拖到-506。
创新药¥300试探仓→8/20如果还没赚钱→触发讨论。
```

### 5. 纳指买入估值阈值

**建议原文**：核心增长层仅明确PE>35卖出，无对应买入估值阈值。

**三问评估**：

| 问题 | 答案 |
|------|------|
| 能阻止历史亏损？ | 不是阻止亏损，是优化买入。但你之前的问题是"不知道什么时候该多买" |
| 规则冲突？ | 无。PE>35卖出已有，补买入侧 |
| 一个月验证？ | 能。mx-data可获取PE分位数 |

**改进后效果**：

```
纳指定投不再是盲目的¥10/天：
  PE≤30%分位 → ¥10/天（现在就是，纳指连跌3天）
  PE≤10%分位 → ¥20/天（加倍，别人恐慌你贪婪）
  PE>70%分位 → 停定投，持有不买

当前纳指连跌3天-3.7%→PE分位数应该不高→正常定投✅
```

## ⚠️ 搁置（3条）

---

### 8. 真正风险平价（波动率加权）

**为什么搁置而非吸收**：

1. **数据不具备**：需要各层持仓近3年波动率。压舱石的数据好找，卫星层创新药+证券+半导体的组合波动率需要自己算——mx-data可以提供但需要逐只查询后合成。

2. **收益不大**：按波动率调整后，卫星层从20%→12-15%，压舱石从45%→50-55%。对¥38k组合来说，调整金额约¥2,000-3,000——不是质变。

3. **但方向对**：先把压舱石→50%、卫星→15%作为"简化版风险平价"，不等波动率数据。

**下月落地前提**：收集完波动率数据→月度归因时计算→v3.3或v3.4落地。

---

### 9. 移动止盈

**为什么搁置而非吸收**：

1. **阶梯止盈刚建立，还没触发过一次**：7/21至今，没有任何卫星触发+10%。立即改=推翻一个还没验证过的规则。这本身就违反Anchor的"规则保护机制"。

2. **但逻辑对**：卖飞+75%（信息产业）是因为没有移动止盈。如果当时设了"高点回撤8%"的保护，至少能吃到一半涨幅。

3. **需要实战数据**：等证券ETF或创新药首次触发+10%止盈后，评估"阶梯止盈有没有让我卖飞"，再决定是否升级到移动止盈。

**下月落地前提**：卫星层首次触发止盈→评估效果→决定是否升级。

---

### 10. 相关性分析（穿透持仓）

**为什么搁置而非吸收**：

1. **需要逐只查询**：穿透10只基金的底层持仓→每只需要mx-data单独查询→10次调用。可以做到，但ROI不高。

2. **问题确实存在**：红利ETF（515180）和证券ETF（512880）底层都重仓银行+金融股。两只合计¥7,734，占组合20%。但红利ETF是压舱石不卖，证券ETF是卫星有止损——它们的风险属性已经不同。

3. **等资产规模上去再弄**：¥38k组合，即使两只100%重叠，也只是一千多块钱的问题。

**下月落地前提**：总资产>¥5万或者月度归因时发现明显问题。

## ❌ 拒绝（3条）

---

### 11. 天弘通利立即移入压舱石 + 核心增长只剩纳指

**为什么拒绝**：

| 原因 | 说明 |
|------|------|
| 核心增长层太空 | 纳指A+C+通利=3只。移走通利→只剩纳指（还限购¥10/天）。核心增长层变成"单品种层"——违背分散原则 |
| 纳指限购 | ¥10/天，无法加速建立仓位。如果纳指暴跌想加仓→加不了 |
| 通利定位已标注 | 先在看板标注"核心增长（偏压舱石）"，实际风险已匹配。机械移动会破坏层结构 |

**什么情况下重新考虑**：纳指限购放开 + 至少有一只新的宽基加入核心增长层。

---

### 12. 回测模块

**为什么拒绝**：

| 原因 | 说明 |
|------|------|
| 测不了行为规则 | Anchor的核心不是交易信号——是"冻结72h""月操作≤4笔""恐慌日豁免"。这些都是**行为规则**，回测测不了"如果7/17你恐慌了会不会割肉" |
| ROI太低 | 搭建回测系统→需要3年历史数据+回测框架+参数优化→至少20小时。换来的只是"DDX金叉买/死叉卖"这种信号回测——和Anchor的纪律体系不是一回事 |
| 实盘数据更有说服力 | 109笔交易+28只清仓+35天迭代→这就是你的回测。真实亏损¥1,138比任何回测都真实 |

**替代方案**：继续维护交易台账。每笔操作的盈亏、原因、对应规则——这就是Anchor的回测。

---

### 13. 底层穿透风控（行业集中度）

**为什么拒绝**：

| 原因 | 说明 |
|------|------|
| 规模太小 | ¥38k组合，穿透到个股层面→发现"你间接持有招商银行¥800"——然后呢？调整吗？手续费都不够 |
| 层级已隔离 | 红利ETF（压舱石）和证券ETF（卫星）的风险属性已被层级规则隔离。即使底层重叠，操作规则完全不同 |
| 不是当前痛点 | 你最大的问题不是"行业集中度太高"——是"中证2000拖了21天才清"。解决时间止损的优先级远高于穿透分析 |

**什么情况下重新考虑**：总资产>¥10万 + 当前痛点全部解决后。
