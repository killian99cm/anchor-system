## 一、每日复盘铁律（永不变更）

### 1.1 你必须提供

| 数据 | 内容 | 为什么重要 |
|------|------|------|
| 基金持仓截图 | 每只基金的持仓金额、日收益、持有收益、累计收益 | 没有真实数据，分析就是猜 |
| 股票持仓 | 515180的持仓/盈亏 | 股票数据是独立系统 |
| 余额宝/现金 | 最新余额 | 活钱是操作的弹药 |
| 操作记录 | 当天做了什么买卖 | 避免我基于旧数据计算 |

### 1.2 我会提供

| 输出 | 内容 |
|------|------|
| 市场全景 | 今天发生了什么、为什么 |
| 逐只分析 | 每只持仓基金的精确诊断 |
| 操作效果 | 上次操作的回顾与评价 |
| 操作建议 | 明天的具体行动（标的+金额+条件） |
| 新机会 | 是否触发关注清单的买入条件 |

### 1.3 数据流

```
你的截图 → portfolio_data.json 更新 → rebuild.py + gen_excel_skill.py
                                            ↓
                              portfolio_analysis.html（看板）
                              portfolio_holdings.xlsx（Excel）
                              deep_review_[日期].md（复盘报告）
```

## 二、长期盈利的基石：纪律

### 2.1 十条铁律（从两周操作中提炼）

| # | 纪律 | 违反后果 | 来源 |
|:--:|------|------|------|
| 1 | **不做主动基金之间的换仓** | 7/6卫星→诺安，11天亏-383 | 课一 |
| 2 | **同一标的月操作≤2次** | 半导体7月操作4次，方向混乱 | 课四 |
| 3 | **盈利品种阶梯止盈** | 一次性卖飞→后悔→追高→亏损 | 课三 |
| 4 | **止损不犹豫** | 港股科技从-50拖到-113 | 课二 |
| 5 | **加仓有触发条件，卖出有止盈线** | 没有规则就是赌博 | 课四 |
| 6 | **每月操作≤4笔** | 14笔/两周=过度交易 | 综合 |
| 7 | **活钱≥¥3,000** | 没有弹药就没有机会 | 纪律 |
| 8 | **进攻/防御 = 50/50** | 偏防御→牛市跑输；偏进攻→熊市扛不住 | 目标 |
| 9 | **持仓≤14只活跃基金** | 超过就没法深度跟踪 | 纪律 |
| 10 | **每笔操作前写理由，次日执行** | 抑制"打新前布局"式冲动 | 课四 |

### 2.2 买入/卖出触发条件（标准化）

| 品种类型 | 买入触发 | 卖出触发 |
|------|------|------|
| 科技/进攻型（半导体等） | 从高点累计跌 **-15%** | 单日反弹 +8% 或 累计+20% |
| 防御型（债券/红利） | 不设——永远持有 | 除非换到更高收益品种 |
| QDII（纳指等） | 定投——不择时 | 纳指PE>35或AI泡沫明确 |
| 新机会（机器人等） | 从高点跌8-10% | 反弹+10%止盈1/3 |
| 证券ETF | PB<1.35买入 | PB>1.6止盈1/3 |

### 2.3 仓位管理规则

| 品种 | 仓位上限 | 单次买入 |
|------|:--:|:--:|
| 单只进攻基金 | ≤¥3,000（约8%） | ¥500 |
| 单只防御基金 | 无上限 | — |
| QDII合计 | ≤¥5,000（约14%） | 定投¥10-20/日 |
| 股票 | ≤¥6,000（约16%） | — |
| 现金/余额宝 | ≥¥3,000 | — |
| 新机会 | ≤¥2,000/板块 | ¥500试探 |

## 六、最重要的三句话

> **1. 不频繁交易。每月4笔以内。每笔操作前写理由，24小时后执行。**

> **2. 亏损时问自己：是逻辑错了还是市场错了？逻辑错了→立刻止损。市场错了→坚定持有甚至加仓。**

> **3. 组合的目标不是每天赚钱，而是每年赚钱。今天的-455是长期盈利的一部分成本。**
