# Anchor 投资体系 v3.2

> 稳如磐石，水滴石穿，锚定纪律。109笔实盘迭代出的基金投资纪律体系。
> **在每一次操作中学习，在每一次失误中总结，持续提高体系的精确度。**

## 进化原则
框架通过实战不断进化。每条规则对应一段历史亏损。新对话开始时自动加载全部记忆。
评分：v1.0(55) → v2.0(68) → v3.0(78) → v3.1(92)
桌面正式版：投资规则手册_v3.1_正式版.md

## 三层结构
- 🛡️ 压舱石层 45%：债券×2 + 515180红利 + 黄金。永远不卖，年再平衡1次
- 🚀 核心增长层 25%：纳指A+C + 天弘通利。定投为主，PE>35才减仓
- 🔥 卫星进攻层 15%：创新药 + 证券ETF + 半导体。止损-8%，浮亏不加仓
- 💰 现金预备层 15%：余额宝。仅压舱石暴跌5%+时动用，不参与卫星

## 关键规则
- **浮亏不加仓**：卫星仓浮盈>3%才能加第二笔，≤首笔50%
- **334分批建仓**：首笔30%→浮盈+连续2天涨→30%→突破20日线→40%
- **卖出冻结72h**：清仓资金在余额宝放满3天才能开新仓
- **卖飞补偿**：卫星止盈时留100份底仓
- **每笔操作必带"错了怎么办"预案**
- **恐慌日豁免**：全市场≥3000只下跌→当日不清仓/不执行止损
- **风口3天确认**：连续3天跑赢大盘≥2%+明确催化+ETF放量，缺一不可
- **beta/alpha拆解**：亏损归因时区分市场下跌(beta)和基金自身问题(alpha)

## 复盘体系
- 每日：触发式检查（止损线/止盈线），5分钟
- 每周：仓位点检，15分钟
- 每月：完整归因（收益拆解+beta/alpha+违规记录），30分钟

## 数据获取（强制规则 — 首位，永不变更）
**所有金融数据优先使用 mx-data**（东方财富官方API，24h）。
覆盖：行情/板块资金流/基金净值/财务数据/技术指标/历史序列。
要求：每一处数据都要深入分析（技术面+基本面+资金面）。

**备选方案（按优先级）**：
1. mx-data（首选，东方财富官方API，24h，最权威）
2. mx-search（备选，东方财富底层）
3. AKShare（备选，免费开源，交易时段可用）
4. WebSearch（兜底，覆盖美股+盘后A股）
5. 用户手机App截图（最终验证）

**任何时候数据质量不能降级。** 首选不可用时自动降级，但必须在报告中标注数据源。
数据准确性 = 决策正确性 = Anchor体系的基石。
