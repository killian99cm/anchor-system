# 体系命名方案

---

## 🥇 首推：磐石体系（Anchor System）

| 维度 | 内容 |
|------|------|
| 中文 | **磐石体系** |
| 英文 | **Anchor Investment System** |
| 缩写 | **AIS** |

### 三层含义

```
第一层：磐 = 稳如磐石
  压舱石层永远不卖，是组合的地基
  对应规则：债券+红利+黄金，年操作0-1次

第二层：石 = 水滴石穿
  复利需要时间。103天太短，3年才见功夫
  对应规则：核心增长层定投为主，持有≥3年

第三层：锚 = 锚定纪律
  船有锚才不被风浪带走。投资者有规则才不被情绪左右
  对应规则：v3.2十四项铁律，每笔操作有预案
```

### 为什么这个名字好

> "磐石"不炫、不浮夸。它准确描述了这个体系的本质：**不是靠预测赚钱，是靠稳固的地基+时间的复利+纪律的执行。** 熊市中是避难所，牛市中是发射台。

## 🥈 备选：层律体系（Stratum System）

| 维度 | 内容 |
|------|------|
| 中文 | **层律体系** |
| 英文 | **Stratum Investment System** |
| 缩写 | **SIS** |

### 拆解

```
层 = 四层金字塔（压舱石→核心增长→卫星进攻→现金预备）
律 = 纪律（每层有规则，每笔有预案，每月有归因）

合在一起：分层而治，以律为纲
```

## 🥉 备选：守正体系（Orthodox System）

| 维度 | 内容 |
|------|------|
| 中文 | **守正体系** |
| 英文 | **Orthodox Investment System** |
| 缩写 | **OIS** |

### 出处

> 《孙子兵法》："凡战者，以正合，以奇胜。"
> 守正 = 压舱石+核心增长（70%），以正合
> 出奇 = 卫星进攻（20%），以奇胜

---

## 🏅 备选：归因体系（Attribution System）

| 中文 | **归因体系** |
| 英文 | **Attribution Investment System** |

### 逻辑

> 归 = 归因（beta/alpha拆解、月度复盘）
> 因 = 因果（每笔操作追因溯果，月底归因找规律）

偏学术，适合量化/分析型投资者。
