# 金融模型实用性分析 — 哪些能真正改进v3.1

---

## 第一类：可以直接落地（3个）

### 1. 凯利公式 → 优化卫星仓位上限 ⭐⭐⭐

```
凯利公式：最优仓位 = (胜率 × 盈亏比 - 失败率) / 盈亏比

你的卫星仓：
  历史胜率：39%（28只清仓，11只盈利）
  盈亏比：平均盈利~+80 / 平均亏损~-80 ≈ 1:1

  最优仓位 = (0.39 × 1 - 0.61) / 1 = -0.22 → 负数！

解读：以你历史39%的胜率，凯利公式说你**不应该下注**。
```

> 这解释了为什么你28只清仓净亏-1029——不是仓位管理问题，是**胜率不够**。

**如何改进**：不是调整仓位上限，是提高胜率。v3.1的风口3天确认+334分批——就是为了把胜率从39%拉到50%以上。每提高1%胜率，凯利公式允许的仓位就大一分。

**落地**：当前卫星单只¥3,000上限**保持不变**，等月度归因中卫星胜率>50%后再讨论上调。

---

### 2. 风险平价 → 验证四层配比 ⭐⭐

```
风险平价逻辑：每层对总风险的贡献应该相等

你的四层（波动率估算）：
  压舱石：波动率~2% × 权重45% = 风险贡献 0.9%
  核心增长：波动率~8% × 权重25% = 风险贡献 2.0%  ← 风险大头！
  卫星进攻：波动率~12% × 权重15% = 风险贡献 1.8%
  现金预备：波动率~0% × 权重15% = 风险贡献 0%

结论：核心增长层贡献了最多风险，但它应该是最稳的。
      卫星进攻层风险贡献反而不如核心增长层高。
```

**落地改进**：

| 层级 | 当前 | 风险平价建议 | 行动 |
|------|:--:|:--:|------|
| 核心增长 | 25% | **20%** | 纳指目标从¥5,000→¥4,000 |
| 卫星进攻 | 15% | **20%** | 创新药+证券可以更重 |
| 压舱石 | 45% | 不变 | — |
| 现金预备 | 15% | 不变 | — |

> 这意味着：**纳指不需要加到¥5,000，卫星可以比现在更重。**

---

### 3. 最大回撤控制 → 组合层面风控量化 ⭐⭐

```
当前v3.1：恐慌日豁免（定性）
改进：量化触发线

总资产从高点回撤：
  -5% → 🟡 卫星仓位减半
  -10% → 🔴 卫星全部清仓
  -15% → 🔴🔴 核心增长也减1/3
```

**落地**：在v3.1中加入这个量化回撤控制表。当前高点¥36,540（7/20）→ 跌破¥34,713（-5%）→ 触发。

## 第三类：理论价值高但暂不落地（2个）

### Black-Litterman模型

```
逻辑：市场均衡配置 + 你的主观观点 → 最优配置

有用但暂不落地的原因：
  需要计算各类资产的相关性矩阵（超出个人投资者能力）
  v3.1的四层配比已经是简化版BL
  
什么时候落地：资产规模>¥10万时可考虑
```

### VaR/CVaR

```
逻辑：95%置信度下，组合一天最大亏损

有用但暂不落地的原因：
  ¥3.6万组合，VaR数值太小，没有决策意义
  更适合百万级以上组合做机构风控
```

## 第四类：纯学术，不适用（3个）
