## 第一章：三层金字塔

### 1.0 配比逻辑（风险平价验证）

```
压舱石：波动率~2%，权重45% → 风险贡献合理
核心增长：波动率~8%，权重20% → 降权（原25%风险过高）
卫星进攻：波动率~12%，权重20% → 升权（释放空间给高胜率卫星）
现金预备：波动率~0%，权重15% → 不变
```

## 第二章：卫星层操作细则

### 2.1 建仓：334分批法

```
首笔 30%：试错仓
  ↓ 条件：连续2天上涨 + 浮盈>3%
第二笔 30%：确认仓
  ↓ 条件：突破20日均线 + 催化落地
第三笔 40%：重仓

全程无浮盈 → 永远不加仓
```

### 2.2 止损：-8% 无条件（含缓冲+恐慌豁免）

| 触发条件 | 行动 |
|------|------|
| 浮亏达到 -8% | 给 **1个交易日缓冲**。缓冲期内反弹→反弹中执行止损；继续跌→无条件止损 |
| **恐慌日豁免** | 全市场≥3000只下跌/百股跌停→**当日不执行止损，次日再判** |
| 卫星层整体亏-15% | 全部清仓→转现金→休息一周 |

### 2.3 止盈：阶梯式 + 留底仓

```
+10% → 卖1/3（锁定利润）
+20% → 再卖1/3（大幅获利）
剩余1/3 → 跌破20日线出清

每次止盈 → 留100份底仓不卖
```

### 2.4 加仓：浮盈才加

```
卫星仓浮亏 → 一分钱不加
卫星仓浮盈>3% → 可加第二笔，≤首笔50%
```

### 2.5 风口识别：三条缺一不可

| # | 条件 | 标准 |
|:--:|------|------|
| ① | 连续跑赢 | **连续3天**跑赢大盘≥2% |
| ② | 明确催化 | 政策/业绩/事件，可查证 |
| ③ | ETF放量 | 成交额>5日均量1.5倍 |

```
风口确认前：仅可 ¥300 试探
风口确认后：首笔30%→第二笔30%
不满足3条→不叫风口→不出重手
```

### 2.6 月度末位淘汰

| 类型 | 条件 | 行动 |
|------|------|------|
| **基金自身问题** | 持续跑输基准+alpha持续为负 | 触发即清仓 |
| **风格系统性下跌** | 全市场同跌，基金未明显跑输 | 降仓控制 |

判断方法：亏损 = beta（指数跌幅）+ alpha（额外跑输）。alpha持续为负→基金问题。

### 4.2 凯利胜率观（新增）

```
凯利公式：最优仓位 = (胜率 × 盈亏比 - 失败率) / 盈亏比

你的历史胜率：39%
→ 凯利公式说你不该下注
→ 解决方案：不是调仓位上限，是提高胜率

v3.2的每一条规则都在帮你提高胜率：
  风口3天确认 → 过滤假信号
  334分批 → 错了代价小
  -8%止损 → 输了不拖
  月度归因 → 知道自己怎么输的

目标：卫星胜率从39%→50%+
达到后再讨论上调仓位上限
```
