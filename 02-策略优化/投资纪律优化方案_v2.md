## 二、v2.0 完整规则

### 规则 1-3：核心仓铁律（永不违反）

**规则1：债券永远不卖。红利ETF永远不卖。纳指只在PE>35时减仓1/3。**

**规则2：核心仓操作节奏**
- 月操作 0-1 次（仅再平衡时）
- 买入前写理由 → **24小时后**执行
- 越跌越买（定投式加仓，不看短期涨跌）

**规则3：核心仓品种上限 6只**
```
当前：鹏华债券 + 中银债券 + 余额宝 + 515180红利 + 纳指100 + 天弘通利 = 6只 ✅
```

---

### 规则 4-7：卫星仓纪律（快速+严格）

**规则4：卫星仓操作节奏**
- 月操作 ≤4 次（买入≤2 + 卖出≤2）
- 买入可以**当天决策、当天执行**（风口不等人）
- 但单次≤¥500，单品种≤¥2,000

**规则5：卫星仓-8%止损（强化版）**

| 条件 | 行动 |
|------|------|
| 单只卫星亏-8% | **无条件清仓**（不等反弹，不问理由） |
| 卫星仓整体亏-15% | 全部卫星清仓→转为现金→休息一周 |

**规则6：卫星仓止盈（阶梯式）**
```
+10% → 卖1/3（锁定利润）
+20% → 再卖1/3（大幅获利）
剩余1/3 → 让利润跑，直到趋势逆转
```

**规则7：卫星仓品种上限 4只**
```
当前：创新药 + 证券ETF + 半导体 + 黄金 = 4只 ✅（已达上限）
新增必须清掉一只旧的后才能开新。
```

---

### 规则 8-10：风口捕捉机制（新增）

**规则8：风口识别标准**
一个板块同时满足以下3条 → 确认为"风口"：

| # | 条件 | 数据来源 |
|:--:|------|------|
| ① | 板块连续3天跑赢大盘≥2% | 每日复盘 |
| ② | 有明确催化（政策/业绩/事件） | 新闻搜索 |
| ③ | ETF连续放量（成交额>5日均量1.5倍） | 行情数据 |

**规则9：风口上车规则**
```
确认风口 → 首笔 ¥500（试探）
第二天继续强势 → 加 ¥500（确认）
第三天仍然强势 → 加 ¥500（重仓）
单风口上限 ¥2,000

如果首笔后第二天就跌-3% → 停止加仓，设-8%止损
```

**规则10：风口下车规则**
```
催化落地（利好兑现） → 当天减仓1/2
连续2天跑输大盘 → 减仓1/2
跌破20日均线 → 全部清仓
```

---

### 规则 11-12：回撤控制（新增）

**规则11：组合层面回撤控制**

| 回撤幅度 | 行动 |
|------|------|
| 总资产从高点回撤 -5% | 🟡 卫星仓位减半，不再开新仓 |
| 总资产从高点回撤 -10% | 🔴 全部卫星清仓，只留核心 |
| 总资产从高点回撤 -15% | 🔴🔴 核心仓也减仓1/3，持有现金 |

**当前状态**：高点~¥37,100（7/14），当前~¥36,191，回撤 **-2.5%** → 正常范围

**规则12：单品种集中度上限**
```
单只核心品种 ≤ ¥7,000（约20%）
单只卫星品种 ≤ ¥3,000（约8%）
单个板块（如科技/金融/医药） ≤ ¥12,000（约34%）
```

---

### 规则 13：月度末位淘汰（新增）

每月最后一个交易日，检视卫星仓：

| 条件 | 行动 |
|------|------|
| 持有>1个月 且 亏损>10% | **清仓**（不留，不犹豫） |
| 持有>2个月 且 仍在亏损 | **清仓**（证明逻辑错了） |
| 持有>3个月 且 收益<5% | **清仓**（机会成本太高） |

> 这就是中证2000/光伏/衡瑞需要在7月底清仓的制度依据。

---

### 规则 14：盈利再投资（新增）

```
卫星仓止盈后：
  50% → 转入核心仓（纳指/债券，长期复利）
  30% → 保留为卫星弹药（等下一个风口）
  20% → 转入余额宝（提高活钱安全垫）
```
