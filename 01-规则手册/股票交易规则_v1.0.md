## 三、未来如果交易其他股票

### 3.1 允许交易的品种

| 分类 | 允许 | 禁止 | 原因 |
|------|:--:|:--:|------|
| 宽基ETF | ✅ | — | 你已在买（515180），可以 |
| 红利/价值ETF | ✅ | — | 压舱石定位 |
| 银行股 | ✅ | — | 已研究过（建行/兴业/平安） |
| 行业ETF | 🟡 | — | 仅限你已持有基金的对应ETF |
| **个股（科技/医药/消费）** | — | ❌ | 研究深度不够 |
| **概念股/题材股** | — | ❌ | 永久禁止 |
| **次新股/ST股** | — | ❌ | 永久禁止 |

### 3.2 买入规则

```
首次买入 ≤ ¥1,000
加仓条件：持有>30天 + 浮盈>5%
单只上限：¥2,750（股票账户50%）
单次操作：≥¥500，禁止碎股交易
```

### 3.3 卖出规则

| 条件 | 行动 |
|------|------|
| 浮亏 -8% | 无条件止损（和卫星层一样） |
| 浮盈 +15% | 卖1/3 |
| 浮盈 +30% | 再卖1/3 |
| 持有>1年+浮盈>50% | 可清仓 |
| 基本面恶化 | 无条件清仓 |

### 3.4 红线

| # | 禁止操作 | 原因 |
|:--:|------|------|
| 1 | **融资/配资/杠杆** | 永久禁用。你见过科创50五天-22% |
| 2 | 日内做T | 你没有盯盘时间 |
| 3 | 跌了补仓 | 和卫星层一样：浮亏不加仓 |
| 4 | 听消息买股 | 你买的银行股研究都没问题，消息股不行 |
| 5 | 同一天买卖同一标的 | 冷静期≥3天 |
