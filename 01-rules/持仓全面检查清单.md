## 每只基金必查六项

| # | 检查项 | 判断标准 | 红灯信号 🚨 |
|:--:|------|------|------|
| 1 | **持有盈亏** | >0 健康 / -5~0% 观察 / <-10% 危险 | 🚨 <-10% → 立即讨论是否清仓 |
| 2 | **累计盈亏趋势** | 近5日是在收窄还是扩大？ | 🚨 连续5天扩大 → 趋势恶化 |
| 3 | **日跌速** | 单日跌幅在加速还是减速？ | 🚨 连续3天加速 → 飞刀别接 |
| 4 | **板块地位** | 板块在涨还是跌？它跑赢还是跑输？ | 🚨 板块涨它跌 → 基金本身有问题 |
| 5 | **框架定位** | 核心还是卫星？符合当前规则吗？ | 🚨 卫星亏-8% → 止损触发 |
| 6 | **持有天数** | 买了多久？是否触发末位淘汰？ | 🚨 >30天+跑输大盘≥5% → 时间止损 |

## 复盘输出格式（标准化）

每次复盘报告中，每只基金必须包含：

```
基金名称
├── 💰 市值 / 持有盈亏 / 累计盈亏 / 今日日收益
├── 📊 六项检查结果（通过✅ / 警告🟡 / 红灯🚨）
├── 🔍 为什么涨/跌（一句话）
└── 🎯 行动建议（明天做什么 + 触发条件）
```
