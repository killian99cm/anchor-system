## 一、四个核心问题

### 问题1：持仓太碎，火力不集中

```
14只基金中：
  7只市值<¥1,000（TMT50 ¥308、高端制造 ¥475、衡瑞 ¥794、半导体 ¥751、
                     光伏 ¥900、黄金联接C ¥1）
  这7只合计 ¥3,229，占基金总市值 11.9%
  但对总收益的贡献 → 几乎为零
  对精力的消耗 → 巨大
```

| 集中度的反面教材 | 数据 |
|------|------|
| 7只小仓合计 | ¥3,229 |
| 如果集中到创新药 | 今天+3.73% = +¥120 |
| 分散在7只的效果 | 今天合计约 -¥48 |

> **同样的本金，集中是+120，分散是-48。这是你最大的效率损失。**

### 问题2：定投惯性——错的品种也在投

```
被清仓/待清仓的品种，历史上都有定投：
  卫星产业C → 6月每天¥10 → 7/6转换（亏）
  诺安研究C → 6月每天¥20 → 7/17全清（-415）
  光伏C → 6月每天¥20 → 仍在持仓（-265）
  中证2000C → 6/22定投¥90 → 6/30转入 → -477
```

> **定投了4只后来被证明是错的品种。不是定投错了——是把定投用在了错的品种上。** 定投应该只用于核心仓（纳指、黄金、债券、红利），不用于卫星仓。

### 问题3：转换是亏损之源

```
6/30 红利低波→中证2000：1848份转入 → 至今-477
7/6  卫星→诺安：988份转入 → 全清-415
────────────────────────────────
两次转换，合计亏损：-892
占总投资亏损的：约60%
```

> 109笔交易中，只有2笔是转换。但这2笔贡献了60%的亏损。v2.0 "不做主动基金转换" 规则是对这两次错误的制度化。
