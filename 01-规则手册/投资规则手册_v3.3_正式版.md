## 第一章：四层金字塔（v3.2配比延续）

### 1.0 配比逻辑（风险平价验证）

```
🛡️ 压舱石：波动率~2%，权重45% → 风险贡献合理
🚀 核心增长：波动率~8%，权重20% → 降权（原25%风险过高）
🔥 卫星进攻：波动率~12%，权重20% → 升权（释放空间给高胜率卫星）
💰 现金预备：波动率~0%，权重15% → 不变
```

| 鹏华债券C | ¥6,600 | 永远不卖 |

| 515180红利ETF | ¥5,500 | 永远不卖 |
| 国泰黄金ETF A | ¥1,500 | 永远不卖，定投¥15/天 |

- 操作频率：**0-1次/年**（仅年度再平衡）
- 卖出条件：**不存在**。除非基金清盘或基本面永久恶化
- **515180红利ETF补充规则**（来自股票交易规则v1.0）：暴涨+30%→卖1/3锁定利润。其余场景不卖。

### 1.2 核心增长层（20%，~¥7,800）

**纳指估值阈值（v3.3新增）**：
| PE分位 | 行动 |

### 1.3 卫星进攻层（20%，~¥7,800）

| 品种 | 目标市值 | 规则 |
|------|------|------|

- 存放余额宝
- 仅用于：①压舱石暴跌5%+补仓 ②核心增长层暴跌10%+补仓
- **不用于卫星层加仓、不开新仓、不日常消费**

## 第二章：卫星层操作细则

### 2.1 建仓：334分批法

```
首笔 30%：试错仓
  ↓ 条件：连续2天上涨 + 浮盈>3%
第二笔 30%：确认仓
  ↓ 条件：突破20日均线 + 催化落地
第三笔 40%：重仓

全程无浮盈 → 永远不加仓
```

### 2.2 止损体系（v3.3升级）

| 触发条件 | 行动 |
|------|------|
| 浮亏达到 -8% | 给 **1个交易日缓冲**。缓冲期内反弹→反弹中执行止损；继续跌→无条件止损 |
| **恐慌日精确化**（v3.3） | 大盘≥3% 或 板块≥5% → **延迟1个交易日执行止损** |
| **时间止损**（v3.3新增） | 卫星持有>30天 + 跑输大盘≥5% → **强制卖出** |
| 卫星层整体亏-15% | 全部清仓→转现金→休息一周 |

### 2.3 止盈：阶梯式 + 留底仓

```
+10% → 卖1/3（锁定利润）
+20% → 再卖1/3（大幅获利）
剩余1/3 → 跌破20日线出清

每次止盈 → 留100份底仓不卖
```

### 2.4 加仓：浮盈才加

```
卫星仓浮亏 → 一分钱不加
卫星仓浮盈>3% → 可加第二笔，≤首笔50%
```

### 2.5 风口识别（v3.3量化升级）

| # | 条件 | 标准 |
|:--:|------|------|
| ① | 连续跑赢 | **连续3日**跑赢沪深300累计≥2% |
| ② | 明确催化 | 政策/业绩/事件，可查证，催化周期≥1周 |
| ③ | ETF放量 | 成交额>20日均量1.5倍 |

```
风口确认前：仅可 ¥300 试探
风口确认后：首笔30%→第二笔30%
不满足3条→不叫风口→不出重手
```

### 2.6 半导体 DDX 过滤器（v3.3实战验证新增）

```
补仓条件：DDX 连续2日为正（放宽原"连3日"）
否决条件：任一日DDX转负 → 补仓取消 → 重新等待连2日为正
今日DDX为负 → 不补，不管价格多低

数据源：mx-data 半导体板块(BK1036) 当日DDX
```

> **8/6实战验证**：DDX前两日+0.183→+0.127，第3日-0.016转负。补仓自动取消。主力-20.73亿净流出中未加仓。

### 2.7 月度末位淘汰（beta/alpha拆解）

| 类型 | 条件 | 行动 |
|------|------|------|
| **基金自身问题** | 持续跑输基准+alpha持续为负 | 触发即清仓 |
| **风格系统性下跌** | 全市场同跌，基金未明显跑输 | 降仓控制 |

```

## 第四章：组合风控

### 4.1 量化回撤控制（8/6重算基准 · 8/7修正）

> **基准修正说明（2026-08-07）**：原基准高点 ¥39,510（8/5）包含已清仓持仓的虚拟市值，导致回撤虚高（8/7 显示 -15.8% 误触发 -15% 线）。经审计统一为 **8/6 清理后真实资产 ¥32,961**。当前总资产 ¥33,261 相对此基准为 +0.9%，处于安全区。

| 总资产从基准回撤 | 行动 |
|:--:|------|
| **-5%** (基准¥32,961 → ¥31,313) | 🟡 卫星仓位减半，不开新仓 |
| **-10%** (→ ¥29,665) | 🔴 卫星全部清仓，只留压舱石+核心增长 |
| **-15%** (→ ¥28,017) | 🔴🔴 核心增长也减1/3，持有现金 |

```
当前基准：¥32,961（2026年8月6日清理后真实资产）
每次复盘自动对比当前总资产 vs 此基准（_meta.peak_assets）
```

### 4.2 再平衡规则（v3.3新增）

```
频率：月度检查（每月第一次复盘）
触发：层级偏离目标±5%以上
  - 压舱石偏离±8% → 再平衡
  - 卫星偏离±3% → 再平衡
方法：卖出超配→买入低配，不新增资金
```

### 4.3 集中度上限

| 维度 | 上限 |

| 单只核心增长 | ≤¥4,000 |

### 4.4 凯利胜率观

```

目标：50%+
