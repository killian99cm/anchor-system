# Anchor 噪声审计框架 v1.1

> 生效：2026-08-10 ｜ v1.1更新：2026-08-15（振幅比/时机偏差真实数据采集 + 规则命中台账）
> 目的：量化市场噪声对 Anchor 的影响，持续优化信号阈值
> 原则：**每一条假信号都是规则优化的素材，不是"运气不好"**

---

## 一、噪声定义（三类）

| 类型 | 定义 | 今天实例 |
|------|------|------|
| **方向反转** | 信号触发后 1-2 个交易日内反向 | DDX 连3日正→8/7补仓→8/10转负 |
| **假逼近** | 接近触发线但未触发，造成心理干扰 | 半导体午盘 -7.9%（差¥13）→尾盘拉回 |
| **盘中虚晃** | 盘中剧烈波动但收盘平复 | 半导体 -1.41%→-0.12%（深V） |

---

## 二、审计指标

### 2.1 信号持久度（Signal Persistence）

每个触发过的信号，记录从触发到消失的持续天数：

```
DDX信号：
├── 7/15-7/16: 正（2天）→ 7/15补仓+200 → 7/17转负 → 假信号 ❌
├── 8/5-8/7:  正（3天）→ 8/7补仓+300 → 8/10转负 → 假信号 ❌

信号准确率 = 正确次数 / 总触发次数
当前 DDX 准确率 = 0/2 = 0% ⚠️ 需调整阈值
```

### 2.2 虚惊指数（Near-Miss Index）

统计盘中接近但收盘未触发的情况：

```
半导体 -8% 止损线：
├── 8/10 午盘 -7.9%（差¥13）→收盘 -0.12% → 虚惊+1
虚惊指数 = 当月虚惊次数 / 交易天数
当前 = 1/1 = 1.0
若 >0.5 → 止损线可能需要微调（如给 0.5% 缓冲带）
```

### 2.3 盘中振幅比（Intraday Swing Ratio）

```
8/10 半导体振幅 = |-1.41% - (-0.12%)| = 1.29%
收盘涨跌 = -0.12%
振幅/收盘 = 10.75x → 高噪声日
阈值：>5x = 高噪声，>10x = 极高噪声
```

### 2.4 噪声评分卡（每周）

| 指标 | 权重 | 本周值 | 档位 |
|------|:--:|------|:--:|
| DDX 信号准确率 | 30% | 0/2=0% | 🔴 |
| 虚惊指数 | 25% | 1/1=1.0 | 🔴 |
| 盘中振幅比 | 20% | 10.75x | 🔴 |
| 操作时机偏差（补仓后次日涨跌） | 25% | -0.12% | 🟡 |

**综合噪声评分**：🔴 高噪声（本周 2/7 交易日）

## 四、规则优化流程

```
噪声审计发现 → 分类 → 提议调整 → 三问评估 → 实施

示例（本次 DDX 假信号）：
发现：DDX 准确率 0/2
分类：信号阈值过松
提议：DDX 连3日正→连4日正 或 连3日正+当日为正
三问：
  Q1 这是否是系统性问题？→ 是，2次触发2次反转
  Q2 调整后能否避免最近一次错误？→ 能，8/7 当日DDX虽为正但已在收窄
  Q3 调整是否增加错过机会风险？→ 多等一天，风险可控
结论：✅ 通过，v3.4 纳入
```

## 五、审计数据存储

| 数据 | 位置 |
|------|------|
| DDX 每日快照 | `Anchor/06-dashboard/noise/ddx_daily.json` |
| 信号触发日志 | `Anchor/06-dashboard/noise/signal_log.json` |
| 虚惊记录 | `Anchor/06-dashboard/noise/near_miss.json` |
| 盘中振幅快照（v1.1） | `Anchor/06-dashboard/noise/swing_daily.json` |
| 操作时机偏差（v1.1） | `Anchor/06-dashboard/noise/timing_daily.json` |
| 规则命中台账（v1.1） | `Anchor/06-dashboard/noise/rule_hits.json` |
| 每周噪声评分卡 | `Anchor/04-reviews/weekly/` 周报中 |

**采集命令（v1.1，noise_audit.py）**：

```
python noise_audit.py --log-swing "2026-08-14" 半导体 +1.5 -2.1 +0.3   # 盘中高/低/收盘涨跌幅
python noise_audit.py --log-timing "2026-08-07" "半导体补仓+300" +0.29 # 操作后次日涨跌
python noise_audit.py --log-rule "-8%止损+缓冲" protected 250 "说明"   # 规则命中（protected/missed/neutral）
python noise_audit.py --weekly   # 评分卡（振幅比/时机偏差/规则台账自动汇总）
```

> 每周评分卡规则：振幅比 ≤2x=20分 / ≤5x=12分 / ≤10x=6分 / >10x=0分；时机偏差 ≤1%=25分 / ≤2%=15分 / ≤3%=8分 / >3%=0分。数据缺失时给中性分并标注「无数据」。
