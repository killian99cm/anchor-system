## 四、7.1% → 10%：最后 2.9% 从哪里来

### 4.1 数学真相

要再提升 2.9%（≈ ¥1,040/年），有三个来源：

| 来源 | 潜力 | 可控性 | 说明 |
|------|:--:|:--:|------|
| **卫星仓超预期** | +1~3% | 🟡 部分可控 | 如果创新药+证券+半导体平均做到20%而非15%，额外贡献+415/年 |
| **市场整体上涨** | +1~2% | 🔴 不可控 | 上证从3900涨回4200（+7.7%），组合会自然增值 |
| **新增本金** | +0.5~1% | 🟢 可控 | 每月定投¥200-500到纳指/证券，一年可增¥2,400-6,000 |

### 4.2 最现实的路径

```
7.1%（优化后组合）
  + 卫星仓超预期（创新药/证券/半导体 做到20%）= +1.2%
  + 市场从3900回到4100（+5%）= +0.8%
  + 每月追加¥300定投 = +0.7%
  ────────────────────────────
  = 约 9.8% ≈ 10%
```

> **结论：10% 不需要完美——只需要优化做到位 + 市场正常波动 + 持续定投。**
