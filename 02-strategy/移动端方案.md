# Anchor 移动端方案 · 脱离电脑

---

## 可以。手机就够了。

---

## 方案：GitHub Actions（免费）+ Server酱（免费）

```
你的手机                      GitHub（云端，免费）
   │                              │
   │  每天 15:30                  │
   │  ← 微信收到行情简报 ←       │ mx-data 自动拉A股+美股
   │                              │ 跑 anchor_analyzer.py
   │  你回：持仓截图              │
   │  ─────────────────→         │
   │                              │ 我补充分析
   │  ← 微信收到完整报告 ←       │ 生成报告
   │                              │
   │  随时随地看                   │ HTML/Excel 自动更新到GitHub Pages
```

## 你需要做的（一次性，10分钟）

| 步骤 | 时间 |
|------|:--:|
| 1. 注册 GitHub 账号 | 2分钟 |
| 2. 创建仓库、上传 Anchor 文件 | 3分钟 |
| 3. 注册 Server酱（微信推送） | 2分钟 |
| 4. 我配置 GitHub Actions | 我写，你复制粘贴 |

## 以后每天

```
15:30 → 微信自动收到推送：
  "Anchor 7/25 行情：上证-1.38% | 半导体DDX转正 | 创新药-0.97%"
  
你回复：持仓截图
  
15:35 → 微信收到完整报告
```
