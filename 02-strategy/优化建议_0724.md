## 2. 相关性检查 ⭐⭐

**问题**：纳指和半导体高度相关。跌的时候一起跌——等于分散了个寂寞。

**简单方法**：复盘时加一句：

```
今日：纳指-2.15% 半导体+0.55%
→ 相关性：今日反向，半导体独立走强
→ 分散有效 ✅
```

**价值**：确认你的卫星层是不是真的在"分散风险"。

---

## 3. 自动化：Python生成复盘草稿 ⭐⭐⭐

**问题**：每天复盘我手动写，格式一致但费时间。

**方案**：一个 Python 脚本，读 JSON → 输出当日复盘模板（填好数字、六项检查预填）。

```
python anchor_review.py
→ 输出：今日所有数字已填好的复盘草稿
→ 我只补充分析判断
```

**价值**：复盘从30分钟→5分钟。

## 4. 月度P&L归因（beta/alpha）⭐

**7月底做一次**：每只亏损基金的亏损，多少是市场跌的、多少是基金自己的锅。

```
中证2000：亏-477
  beta：小盘指数跌15%×仓位 → -307（系统性）
  alpha：基金跑输-170（基金自己的问题）
  
结论：alpha为负→清仓是正确的。不是风格问题，是基金问题。
```

---

## 5. 买入清单机制 ⭐

**问题**：资金解冻后"该买谁"靠每次复盘判断。

**方案**：维护一张清单：

```
待买入清单（按优先级）：
  1. 纳指加仓 ¥1,600 — 等限购放开
  2. 创新药加仓 ¥500 — 等风口确认（3天跑赢）
  3. 半导体补仓 ¥500 — 等DDX连3日为正+浮亏转正
  4. 证券加仓 ¥500 — PB<1.35或回调>3%
```

每次复盘检查触发条件。不被市场情绪干扰。
