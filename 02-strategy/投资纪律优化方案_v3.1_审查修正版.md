## 一、吸收的修正（15条）

### 修正1：区分beta与alpha亏损 ⭐⭐⭐

```
旧：中证2000亏477 → "增强方向错误，清仓"
新：亏损拆成两块
  ├── beta：小盘风格极端下跌（系统性风险，全市场5000+跌停）
  └── alpha：增强跑输指数（7/16指数+0.64%，基金-2.13%←这才是清仓依据）

以后每只亏损基金都做这个拆解。
```

### 修正2：恐慌日不执行清仓 ⭐⭐⭐

```
旧：7/20建议明天清仓四只
新：全市场3000+下跌/百股跌停的极端情绪日 → 不清仓
   清仓放在情绪修复后的第一个反弹日
   
   明天（7/21）判断：美股半导体+3%→A股大概率反弹
   → 如果是反弹日 → 执行清仓 ✅
   → 如果继续恐慌 → 推迟到反弹日
```

### 修正3：风口加仓严守3天规则 ⭐⭐⭐

```
旧：创新药单日+3.73%→"风口确认"→加仓800
新：
  明天（7/21）仅试探 ¥300（不是800）
  连续2天跑赢大盘 → +¥500
  连续3天跑赢+ETF放量 → 风口确认
```

## 二、反驳的修正（3条）

### 反驳1：中证2000"等反弹再清"

> 审查建议：等小盘反弹后清仓，不在情绪冰点卖出。

**反驳**：从7/14等到7/20，从-204等到-506。不是没等——是等了6天，每天多亏50-150。

**折中方案**：**在下一个反弹日清仓，但必须是一个明确的反弹日。** 明天美股半导体+3%→如果A股高开反弹→当天清。如果明天继续跌→推迟到下一个反弹日。不给无限等待找借口，也不在恐慌日割肉。

### 反驳2：补仓的"长期修复"逻辑

> 审查建议：若反弹20%，补仓多赚100元，补仓价值被低估。

**反驳**：补仓的前提是"品种长期逻辑成立"。中证2000增强C的alpha持续跑输基准——7/16指数涨它跌——增强因子在当前环境中失效。逻辑不成立时，补仓=往漏水桶里加水。

**接受部分**：补仓分析确实应该展示上涨/下跌两种情景，以后做中立化处理。

### 反驳3：月操作上限调到6笔

> 审查建议：月操作≤6笔。

**反驳**：35天109笔的背景下，放宽上限=开倒车。

**折中方案**：正常月≤4笔。**结构调整月（如7月清理4-5只基金）≤6笔**，但超额部分必须在月度复盘中逐笔说明原因。
