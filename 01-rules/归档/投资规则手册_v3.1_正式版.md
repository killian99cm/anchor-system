## 第二章：卫星层操作细则

### 2.1 建仓：334分批法

```
首笔 30%：试错仓
  ↓ 条件：连续2天上涨 + 浮盈>3%
第二笔 30%：确认仓
  ↓ 条件：突破20日均线 + 催化落地
第三笔 40%：重仓

全程无浮盈 → 永远不加仓
```

### 2.2 止损：-8% 无条件（含缓冲）

| 触发条件 | 行动 |
|------|------|
| 浮亏达到 -8% | 给 **1个交易日缓冲**。缓冲期内若反弹→反弹中执行止损；若继续跌→无条件止损 |
| **恐慌日豁免** | 全市场≥3000只下跌/百股跌停的极端情绪日→**当日不执行止损**，次日再判 |
| 卫星层整体亏-15% | 全部卫星清仓→转现金→休息一周 |

### 2.3 止盈：阶梯式 + 留底仓

```
+10% → 卖1/3（锁定利润）
+20% → 再卖1/3（大幅获利）
剩余1/3 → 让利润跑，直到跌破20日线

每次止盈 → 留100份底仓不卖
  作用：涨了跟着赚（不踏空），跌了忽略不计（不心疼）
```

### 2.4 加仓：浮盈才加

```
卫星仓处于浮亏状态 → 一分钱不加
卫星仓浮盈>3% → 可加第二笔，≤首笔50%
```

### 2.5 风口识别：三条缺一不可

| # | 条件 | 标准 |
|:--:|------|------|
| ① | 连续跑赢 | **连续3天**跑赢大盘≥2% |
| ② | 明确催化 | 政策/业绩/事件，可查证 |
| ③ | ETF放量 | 成交额>5日均量1.5倍 |

```
风口确认前：仅可 ¥300 试探
风口确认后：首笔30%→第二笔30%
不满足3条→不叫风口→不出重手
```

### 2.6 月度量淘汰

| 类型 | 条件 | 行动 |
|------|------|------|
| **基金自身问题** | 持续跑输基准+alpha失效 | 触发即清仓，不等月末 |
| **风格系统性下跌** | 全市场同跌，基金未明显跑输 | 降仓控制，不轻易清仓 |

判断方法：亏损拆成beta（指数跌了多少）+ alpha（基金额外跑输多少）。alpha持续为负→基金问题。beta为主→风格问题。

## 第三章：交易纪律

### 3.1 负面操作清单（永久禁用）

| # | 操作 | 历史代价 | 替代方案 |
|:--:|------|------|------|
| 1 | 主动基金之间转换 | -¥892 | 清仓→**冻结3天**→再买 |
| 2 | 亏损卫星仓补仓 | -506→ | 规则：浮亏不加仓 |
| 3 | 卖出后当天买入新标的 | 两次转换 | 冻结3天 |
| 4 | 产能过剩行业主题基金 | -310 | 不进候选池 |
| 5 | 日定投卫星品种 | 卫星/诺安/光伏 | 定投只做压舱石+核心 |
| 6 | 涨了才问要不要买（FOMO）| — | 只按风口标准入场 |

### 3.2 冻结规则

```
任何卖出回笼的资金 → 余额宝放满72小时 → 才能开新仓

为什么：两次转换-892都是当天冲动操作
72小时后：冲动消退，理性回归
```

### 3.3 操作节奏

| 类型 | 买入 | 卖出 |
|------|------|------|
| 决策方式 | 提前1天写理由+金额+止损位 | 止损：立刻执行。止盈：可缓1天确认 |
| 频率 | 正常月≤2笔 | 正常月≤2笔 |

### 3.4 每笔操作必带"错了怎么办"

以后每次给出操作建议，必须附带：

```
操作：创新药 +300
错了怎么办：
  - 跌-8%→止损¥240。逻辑没坏但买贵了
  - 加仓后连续3天跑输大盘→停止后续加仓，观察
```

## 第五章：复盘体系

### 5.1 每日触发式检查（5分钟）

只看三件事，不看总盈亏：
- [ ] 有没有品种触发止损线（-8%）？
- [ ] 有没有品种触发止盈线（+10%/+20%）？
- [ ] 有没有品种触发风口买入条件？

### 5.2 每周仓位点检（15分钟）

- [ ] 四层占比是否偏离目标>5%？
- [ ] 本周有违规操作吗？
- [ ] 下周操作计划

### 5.3 每月完整归因（30分钟）

```
1. 本月收益：_____元（压舱石贡献___/核心增长___/卫星进攻___）

2. 亏损拆解（每只亏损基金）：
   基金A：beta亏___% + alpha亏___%
   → 判断：基金自身问题/风格系统问题

3. 违规操作记录：
   _____（逐笔说明原因）

4. 错误台账更新：
   _____（本月新犯的错误）
```

### 5.4 亏损归因模板

```
基金：中证2000增强C
总亏损：-477元
  ├── beta亏损：指数下跌X% × 仓位 = -XXX元（系统性）
  └── alpha亏损：基金跑输指数Y% × 仓位 = -XX元（基金自身）
结论：alpha持续为负→基金自身问题→末位淘汰
```

## 第六章：搜索与数据规则

### 6.1 搜索铁律

```
⚠️ 每次搜索市场数据前，必须先确认当前真实日期和时间。
1. 确认今天是几月几号
2. 确认现在是几点
3. 再搜索对应日期的行情
绝不搜索未来日期。
```

### 6.2 数据基准

每次复盘前自动调用记忆中的基准数据：
- 14只基金成本价与份额
- 股票515180成本（1.310×4000股）
- 现金总额（余额宝+银行卡≈¥8,000）
- 定投清单
- 完整交易历史

用户只需提供：当日盈亏+操作确认。
