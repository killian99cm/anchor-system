# ⚓ 月度归因执行清单（八步模板）

> 每月 1-7 号执行一次。完整归因约 30 分钟。
> 命令口令：**"月度归因"**
> 保存为：`04-reviews/月度归因_YYYY年M月.md`

---

## ✅ 八步流程

| 步骤 | 内容 | 数据来源 | 完成 |
|:--:|------|------|:--:|
| **1. 统计交易** | 本月全部买卖/定投/转换笔数、金额、操作日期 | `portfolio_data.json` transactions + 用户提供 | ☐ |
| **2. 月度总账** | 月初/月末总资产、真实盈亏(剔除资金转入!)、日均盈亏 | 用户提供收益数据(以用户为准,勿自行用 mx-data 计算) | ☐ |
| **3. 基准对比** | 上证 / 科创50 / 沪深300 月度涨跌,组合 vs 基准超额 | mx-data | ☐ |
| **4. 亏损拆解** | 最大亏损日 Top5 + 最大盈利日 Top3 + 盈亏比 | 每日复盘 | ☐ |
| **5. 卫星胜率** | 本月卫星操作笔数、胜负、胜率(目标 50%+);beta/alpha 拆解(基金 vs 板块) | transactions + 复盘 | ☐ |
| **6. 违规检查** | 逐条对照:浮亏加仓/72h买回/月操作超限/DDX负补仓/溢价>3%建仓;零违规? | gen_monthly_attribution.py 自动检测 + 人工确认 | ☐ |
| **7. 规则三问评审** | 每条新规则提案回答:能阻止哪段历史亏损?与现有规则冲突吗?一个月能验证吗? → 三过吸收/两过搁置/一过拒绝 | 规则手册 v3.3 | ☐ |
| **8. 版本与归档** | 更新规则手册版本号 + CHANGELOG + 体系总览 + 记忆同步 + 归档旧版 | 07-memory/ 双向同步 | ☐ |

---

## 📋 月度归因报告结构（沿用 7 月版）

```
# ⚓ Anchor 月度归因报告 — YYYY年M月
## 一、月度总账（真实盈亏/日均/vs 基准）
## 二、亏损拆解（最大亏损日/盈利日/盈亏比）
## 三、卫星胜率（操作清单/胜率/beta-alpha 拆解）
## 四、规则执行评分（每条规则 1-10 分）
## 五、违规记录
## 六、规则修正提案（三问评估）
## 七、下月计划
```
